Phase A bridge: send SOL or USDC on Solana to the treasury, then a relayer credits HOWL to this wallet. Semi-custodial — not a trustless bridge.

Bridge offline on the server. Operator must set deposit treasury + enable Howl Swap.

Your SOL address is used to send the deposit.

Your order

How it works

  1. Quote shows HOWL you’ll receive (minus bridge fee).
  2. Create order → send the exact SOL/USDC amount to the deposit address from your Solana wallet (Phantom, etc.).
  3. Relayer detects the deposit and sends HOWL to your address.
  4. A miner must confirm the HOWL tx on the Howl network.

Oracle

      

        
Little multi-chain oracle

        
Post observations about other chains onto Howlcoin. Anyone can read the feed — a lightweight on-chain notice board not a trustless bridge.

      

      

        
How to run an observation

        
    
          
  1. Unlock this wallet with HOWL for fees (about 1 HOWL per observation paid to miners).
    2. 
          
  2. Quick path: tap Observe live chains below. The app reads Howl height, Ethereum block, Solana slot, and Tezos level, then posts each key on-chain.
    3. 
          
  3. Manual path: fill Source chain + Key + Value (e.g. ethereum / eth.block_height / 21000000) and tap Post.
    4. 
          
  4. Wait for a miner to include your tx (mempool → confirmed). Local node: mine from the node dashboard; public chain: wait for the network.
    5. 
          
  5. Read results in the Oracle feed on this page (also on Howlscan via API /api/public/oracle).
    6. 
        

        
Example keys: howl.height, eth.block_height, sol.slot, xtz.level. Latest value wins per key.

      

      

        
Observe live chains

        
Fetches current tips from public RPCs and queues oracle txs from your address. Needs network access + enough HOWL for fees.

        
        

        

      

      

        
Manual observation

        
Post any key/value you want tagged by source chain. Still costs the min network fee per post.

        
        
        
        
        
        
        
      

      

        
Oracle feed (on Howlcoin)

        
Latest observation per key. Empty until posts are mined.

Contracts

      

        
Howl Script Contracts

        
Native on-chain templates — not EVM. Deploy a tip jar, timelock, or escrow. Funds lock in the contract until you call a method. Fee ≈ 1 HOWL per deploy/call.

        
    
          
  1. Tip jar — friends donate HOWL; you withdraw anytime.
    2. 
          
  2. Timelock — lock HOWL until a future block height, then claim.
    3. 
          
  3. Escrow — buyer funds; release to seller or refund after height / via arbiter.
