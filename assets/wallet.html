Howlcoin Wallet

The wallet is a home-screen app on your computer or phone. It talks to your local node — it does not hold keys on howlscan.org.

1. Run a node

On your Mac / PC, start Howlcoin connected to the public seed:

python3 -m howl node --connect 147.182.223.204:42069

Dashboard opens at http://127.0.0.1:42070/

2. Open the wallet page

On the same device as the node:

Open wallet → http://127.0.0.1:42070/app Node portal

3. Add to Home Screen (required)

The wallet will not launch in a normal browser tab. You must install it first:

iPhone / iPad (Safari)

  1. Open http://127.0.0.1:42070/app in Safari
  2. Tap Share → Add to Home Screen
  3. Open Howlcoin from your home screen

Android (Chrome)

  1. Open the wallet URL in Chrome
  2. Menu ⋮ → Install app or Add to Home screen
  3. Open Howlcoin from the home screen

Desktop

  1. Open the wallet URL in Chrome / Edge
  2. Use Install app / create shortcut
  3. Launch the installed app

4. Create wallet

After the home-screen app opens, tap Create wallet. Then back up your recovery phrase under Security.

Features

  • Send & receive HOWL
  • Network fee (min 1 HOWL) paid to miners
  • BIP39 recovery phrase backup
  • Optional PIN / Face ID / Touch ID
