Howlcoin Wallet

Use HOWL on the public chain from any phone or computer. Keys stay on your device — Howlscan never holds them.

Open public wallet →

What it does

  • Syncs balance & history from the live public ledger
  • Send / receive HOWL (network fee paid to miners)
  • Create or restore with a 12-word recovery phrase
  • Works on the go — not limited to the computer running a node

Home Screen (recommended)

For the best app experience, open the wallet and use Add to Home Screen / Install app, then launch Howlcoin from your home screen.

Run a full node (optional)

Miners and power users can still run a local node for P2P + mining. The public wallet does not require that.
