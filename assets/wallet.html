Howlcoin Wallet

Use HOWL on the public chain from any phone or computer. Keys stay on your device — Howlscan never holds them.

Open wallet →

Need HOWL L1 / SOL / City? Use the classic multi-chain wallet.

What it does

  • Syncs HOWL balance & history from the live public ledger
  • Send / receive HOWL (network fee paid to miners)
  • Face ID / Touch ID unlock + Google Authenticator 2FA
  • Deposits for SOL, ETH, USDT/USDC (ERC-20 + SPL), top tokens, and custom tokens
  • Swap on Solana via Jupiter (SOL ↔ USDC/USDT)
  • DApp browser with bookmarks (Jupiter, Raydium, Uniswap, …)
  • Create or restore with a 12-word recovery phrase on any device

Other cryptocurrencies stay on their own networks — they are not auto-swapped into HOWL unless you use Swap (Solana pairs).

Home Screen (recommended)

For the best app experience, open the wallet and use Add to Home Screen / Install app, then launch Howlcoin from your home screen.

Run a full node (optional)

Miners and power users can still run a local node for P2P + mining. The public wallet does not require that.
